ClipKeyboard プライバシーポリシー

最終更新日: 2026年11月1日

ClipKeyboard(以下「本アプリ」)は、利用者の入力内容を開発者が収集することはありません。本ポリシーは、本アプリおよび本アプリに含まれるキーボード機能が扱う情報について説明します。

1. 収集する情報

開発者は、利用者の入力内容・クリップボードの内容・ユーザー辞書・利用状況などの個人情報を、開発者のサーバーに送信・保存しません。本アプリは開発者が運営するサーバーを持たず、広告や解析(トラッキング)のための SDK も使用していません。

2. 端末内に保存される情報

次の情報は、利用者の端末内(本アプリとキーボードの共有領域)にのみ保存されます。

  • クリップボード履歴(フルアクセスを許可した場合に、コピーした文章を最大50件まで保存)
  • ユーザー辞書に登録した単語
  • かな漢字変換の学習データ
  • Anthropic の API キー(端末のキーチェーンに暗号化して保存)

これらはアプリ内の操作(履歴の削除、辞書の削除)またはアプリの削除によって消去できます。

3. 外部サービスへの送信(AI 機能)

AI 書き直し機能(敬語・誤字修正・翻訳など)は、利用者が自身の Anthropic API キーをアプリに設定し、機能を実行した場合にのみ動作します。その際、書き直しの対象として選択した文章(選択範囲、またはカーソルより前の文章)が Anthropic, PBC の API(api.anthropic.com)へ送信されます。送信された情報の取り扱いは Anthropic のプライバシーポリシーに従います。API キーを設定しない場合、文章が外部に送信されることはありません。

4. フルアクセスについて

キーボードの「フルアクセスを許可」は、クリップボード履歴の読み取りと AI 機能の通信のためにのみ使用します。フルアクセスを許可しなくても、文字入力・かな漢字変換・ユーザー辞書は利用できます。

5. 第三者への提供

上記 3 の AI 機能を利用者が実行した場合を除き、利用者の情報を第三者に提供することはありません。

6. 子どものプライバシー

本アプリは、子どもから意図的に個人情報を収集することはありません。
